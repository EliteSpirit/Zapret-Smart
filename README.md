# Zapret Smart

GUI для обхода DPI на Windows со встроенным конструктором и поиском стратегий. Движок — форк `nfq/` из [zapret](https://github.com/bol-van/zapret) (winws + WinDivert).

## Состав

| Путь | Что это |
|---|---|
| `engine/nfq` | Исходники движка (форк zapret, MIT). Источник и коммит — `engine/UPSTREAM.txt` |
| `engine/files/fake` | Комплектные фейковые пакеты для стратегий |
| `src/ZapretSmart.Core` | Формат стратегий, белый список опций движка, сборка командной строки, запуск движка, поиск стратегий, отчёт для сообщества |
| `src/ZapretSmart.App` | Интерфейс (Avalonia): обход, конструктор стратегий, поиск, настройки |
| `strategies/presets` | Встроенные стратегии |
| `lists` | Встроенные списки доменов |

## Формат стратегии

```json
{
  "id": "general-multisplit",
  "name": "Общая: fake + multisplit",
  "intercept": { "tcp": "80,443", "udp": "443" },
  "profiles": [
    { "hostlist": "general", "args": ["filter-tcp=443", "dpi-desync=fake,multisplit", "dpi-desync-split-pos=1,midsld"] }
  ]
}
```

`args` — опции движка без `--`, по порядку применения. Принимаются только опции из белого списка (`EngineOptionCatalog`) с проверенными значениями. Фейковые пакеты задаются только hex-строкой или именем комплектного файла. Пути к файлам, `--debug`, `--wf-raw`, hostlist/ipset в стратегии запрещены: стратегии могут приходить из сети, а движок работает с правами администратора.

## Поиск стратегии

1. Каждый сайт из списка проверяется без обхода: TLS-рукопожатие, ответ и чтение не меньше 64 КБ, чтобы поймать блокировки, которые замораживают поток после ~16 КБ. Открывшиеся сайты исключаются.
2. Перебор техник: по одному представителю каждого семейства (multisplit/multidisorder, фейки с разными fooling, autottl, seqovl, fakedsplit и т.д.). Движок запускается с кандидатом, заблокированные сайты проверяются параллельно.
3. Доводка: у двух лучших меняется по одному параметру (позиция разреза, число повторов, fooling, ttl, фейковый пакет).
4. Повторная проверка: победитель прогоняется ещё два раза. Кандидат, который сработал однажды, не выигрывает.

Лимит времени по умолчанию 6 минут. Если движок трижды подряд не запускается, поиск прерывается. Проверки идут мимо системного прокси, иначе проверялся бы прокси, а не обход. Цели, которые не открылись ни с одной техникой, показываются отдельно: это блокировка по IP или подмена DNS, стратегия тут не поможет.

Найденная стратегия сохраняется как своя и перехватывает TCP 80/443. QUIC поиск не проверяет, поэтому UDP не перехватывается: браузер переключится на TCP.

## Обмен с сообществом

Выключен по умолчанию. Сервера базы пока нет, поэтому ничего никуда не отправляется. Правила уже зафиксированы в коде и тестах (`CommunityReports`):
- отчёт содержит только ASN, регион (субъект), параметры стратегии и метрики;
- отчёт формируется, только если поиск шёл по стандартному набору сайтов: свой набор — это отпечаток интересов человека;
- стратегия из базы проходит тот же белый список, что и всё остальное.

## Сборка

Нужен .NET 8 SDK.

```
dotnet test
dotnet run --project src/ZapretSmart.App
```

Движок собирается в Cygwin (`gcc-core`, `make`, `zlib-devel`): `make -C engine/nfq cygwin64`. Готовую сборку (GUI + winws.exe + WinDivert + cygwin1.dll) собирает CI: артефакт `ZapretSmart-win-x64`.

Если задать `ZS_ENGINE=<путь к winws.exe или nfqws>`, тесты дополнительно прогонят пресеты, все допустимые значения опций и все кандидаты поиска через `--dry-run` настоящего движка. С `ZS_LIVE=1` и winws.exe (Windows, права администратора) запускается настоящий перехват через WinDivert.

Свои стратегии и списки доменов лежат в `%APPDATA%\ZapretSmart`.
